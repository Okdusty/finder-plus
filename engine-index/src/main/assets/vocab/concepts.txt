# Concept vocabulary — the open-set labels the app recognizes without being taught.
#
# This file is DATA, not code: edit it to change what the recognizer knows, ship a
# different one per deployment, or drop a replacement at files/vocab/concepts.txt on the
# device to override it at runtime. No rebuild required.
#
# Format:
#   - "# ..."            a comment (ignored)
#   - "name :: gate"     starts a domain. The gate is the stage-1 caption phrase scored to
#                        decide whether the domain applies at all.
#   - "name :: gate :: entity"   marks a domain as named-entity: held to a higher confidence
#                        floor and only ever proposed (never auto-applied), because a wrong
#                        name is worse than no name.
#   - any other line     a concept belonging to the current domain (stage-2 label).
#
# Keep concepts naming *content, never medium*: "video call", not "screenshot of a video call".
# Order is preserved. Concepts and gates may be in any language; they are matched by the CLIP
# text tower, so they only need to describe the image well.
